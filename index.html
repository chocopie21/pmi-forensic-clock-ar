Cara Bermain

Ikuti 4 langkah investigasi untuk mengungkap kebenaran di balik setiap kasus.

01

Setup & Buka Kasus

BRIEFING

Tarik Kartu TKP, baca skenario kasus, dan input data ke Web Dashboard.

▸

Tarik satu Kartu TKP dari tumpukan dan baca skenario kasus yang tertulis dengan cermat.

▸

Ketikkan data lingkungan — suhu ruangan, kondisi pakaian, dan berat badan korban — ke Web Dashboard di laptop.

📋 Baca Skenario 🌡️ Input Suhu 💻 Web Dashboard
02

Investigasi AR

SCANNING

Taruh Kartu Tindakan di atas slot Board, scan dengan HP untuk melihat visual 3D.

▸

Taruh Kartu Tindakan di atas slot yang sesuai di Board Anatomi (Kepala / Dada / Abdomen / Pelvis).

▸

Arahkan kamera HP untuk scan marker AR dan lihat visual 3D jenazah muncul di layar.

▸

Ekstrak data penting seperti suhu rektal dan pola lebam mayat.

📱 Scan AR 🧍 Visual 3D 📊 Ekstrak Data
03

Kalkulasi

PROCESSING

Tekan tombol kalkulasi di Web Dashboard untuk memproses rumus Nomogram Henssge.

▸

Tekan tombol kalkulasi di Web Dashboard untuk memproses rumus Henssge.

▸

Data dari AR — suhu tubuh, berat badan, dan faktor koreksi lingkungan — diolah otomatis.

📐 Rumus Henssge ⚡ Auto-Calculate 🔧 Faktor Koreksi
04

Vonis & Skoring

VERDICT

Tim diskusi simpulkan tebakan, lalu buka "Segel Otopsi" untuk cek akurasi.

▸

Tim berdiskusi dan menyimpulkan tebakan jam kematian dan penyebab kematian.

▸

Buka "Segel Otopsi" di web untuk melihat jawaban sesungguhnya.

▸

Tebakan tepat? Raih Skor 100! 🏆
